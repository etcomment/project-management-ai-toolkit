# ChatGPTでのコンテキストファイルの使い方

`contexts/` と `prompts/` のファイルを ChatGPT で活用するための手順を説明します。

> [!IMPORTANT]
> 案件情報を入力する前に、顧客名・個人名・認証情報等をマスキングしてください。
> AI出力は業務判断の代替ではありません。出力内容は必ず人間が確認してください。

---

## 事前設定と都度利用の考え方

すべてのコンテキストファイルを常に読み込ませる必要はありません。

おすすめは以下です。

### 常に使う

- `PM_CONTEXT.md`
- `docs/ai-safety.md`

### 必要なときだけ使う

- 進捗報告：`STATUS_REPORT_CONTEXT.md`
- 課題・リスク：`ISSUE_RISK_CONTEXT.md`
- 顧客説明：`CLIENT_COMMUNICATION_CONTEXT.md`
- 炎上初動：`FIRE_RESPONSE_FIRST_72H.md`
- 議事録：`MEETING_MINUTES_CONTEXT.md`
- スコープ変更：`SCOPE_CHANGE_CONTEXT.md`
- 遅延リカバリー：`DELAY_RECOVERY_CONTEXT.md`

必要なコンテキストだけを追加することで、AIへの指示が明確になり、不要な情報を減らせます。

---

## 基本手順

1. **`PM_CONTEXT.md` を読む**
   `contexts/PM_CONTEXT.md` を開き、PM業務の共通前提コンテキストを確認する

2. **用途別コンテキストを選ぶ**
   目的に合った `contexts/` のファイルを選択する（[用途別の組み合わせ例](#用途別の組み合わせ例)を参照）

3. **必要に応じて `prompts/` のテンプレートを使う**
   `prompts/` のファイルを開き、依頼文のテンプレートを確認する

4. **案件情報をマスキングして入力する**
   顧客名・個人名・認証情報等を[プレースホルダーに置き換え](#入力前のマスキング例)てから入力する

5. **AI出力を人間が確認する**
   出力をそのまま使用せず、事実確認・修正・承認を人間が行う

## 利用パターン別の手順

### 通常チャットでの利用

```text
# 以下のコンテキストを前提として振る舞ってください

[PM_CONTEXT.md の内容をここに貼り付ける]

---

# 追加コンテキスト

[用途別コンテキストファイルの内容をここに貼り付ける]

---

# 依頼内容

[prompts/ のテンプレートを参考に、案件情報（マスキング済み）を添えて記述する]
```

### Projects での利用

1. ChatGPT でプロジェクトを新規作成する
2. 「Instructions」に `project-instructions.md` の内容を設定する
3. 以降のチャットでは用途別コンテキストと案件情報のみを入力する

```text
以下のコンテキストで進捗報告を整理してください。

[STATUS_REPORT_CONTEXT.md の内容をここに貼り付ける]

【今週の状況（機密情報はマスキング済み）】
- 完了：〇〇機能の実装
- 遅延：〇〇連携が1週間遅延
- 課題：〇〇の仕様が未確定
```

### カスタムGPT での利用

カスタムGPTに `PM_CONTEXT.md` 等をKnowledgeとして設定済みの場合、
用途別コンテキストと案件情報だけを入力すれば対応できます。

```text
以下のプロジェクト状況を課題・リスク観点でレビューしてください。

[ISSUE_RISK_CONTEXT.md の内容をここに貼り付ける]

【課題一覧（機密情報はマスキング済み）】
- 課題1：〇〇モジュールのパフォーマンス問題（担当：エンジニアA、期限未定）
- 課題2：〇〇APIの仕様未確定（影響：3機能が着手不可）
```

## 入力前のマスキング例

AIに入力する前に、以下のように実在情報をプレースホルダーに置き換えてください。

| 置き換え前（例） | 置き換え後（例） |
|---|---|
| 株式会社〇〇（顧客名） | 顧客A |
| 田中 太郎（担当者名） | 担当者A |
| api_key_xxxxxxxxxx | （削除） |
| 見積金額：3,500万円 | 見積金額：数千万円規模 |
| 2025年3月31日が納期 | 第1四半期末が納期 |
| プロジェクト名：〇〇システム刷新 | プロジェクトX |

## 出力確認チェックリスト

AI出力を実務で使う前に、以下を確認してください。

- [ ] 出力内容が実際の案件状況と一致している
- [ ] 推測・仮定に基づく表現が適切に扱われている
- [ ] 顧客・社内の関係性に合ったトーン・表現になっている
- [ ] 契約・費用・責任範囲に関する表現が正確である
- [ ] 顧客提出前に上長・担当者のレビューを受けている
- [ ] AI出力であることを踏まえた上で、最終判断を人間が行っている
