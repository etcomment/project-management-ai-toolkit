> [!NOTE]
> Roadmap items reflect current planning and do not constitute binding commercial commitments.
> Security, confidentiality safeguards, and human-in-the-loop governance remain top priorities.

## Out of Scope (Not Planned)

The following items are intentionally excluded by design:

- Executable hooks or background scripts
- Automated shell or PowerShell scripts
- Pre-configured MCP servers or daemon configurations
- Automated commit or auto-deploy GitHub Actions workflows
- Examples requiring live commercial API keys
- Examples incorporating real, proprietary client project data

This repository maintains a strict focus as a **safe, advisory AI toolkit for project management professionals**, deliberately excluding autonomous execution mechanisms.
