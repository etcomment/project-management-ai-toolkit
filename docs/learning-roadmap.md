# Learning Roadmap

A structured learning progression for Project Managers, PMOs, and Tech Leads seeking to master AI-assisted delivery management.

---

## Stage 1: Foundations of PM × AI (Day 1 to 7)

**Goal**: Understand the core mental model of AI Contexts and master safe prompting.

- [ ] Study [`docs/ai-safety.md`](ai-safety.md) and establish data sanitization habits.
- [ ] Understand the role of [`contexts/PM_CONTEXT.md`](../contexts/PM_CONTEXT.md) as a foundational mental model.
- [ ] Try generating dual status reports using [`contexts/STATUS_REPORT_CONTEXT.md`](../contexts/STATUS_REPORT_CONTEXT.md).
- [ ] Walk through the practical scenario in [`examples/status-report-example.md`](../examples/status-report-example.md).

---

## Stage 2: Risk & Issue Auditing (Day 8 to 21)

**Goal**: Move beyond simple drafting; leverage AI for critical operational review and risk discovery.

- [ ] Audit an active issue backlog using [`contexts/ISSUE_RISK_CONTEXT.md`](../contexts/ISSUE_RISK_CONTEXT.md).
- [ ] Run a project health check using [`contexts/PROJECT_HEALTH_CHECK.md`](../contexts/PROJECT_HEALTH_CHECK.md).
- [ ] Deploy Claude Code Skills like `project-risk-radar` and `issue-risk-review`.
- [ ] Practice blameless root-cause analysis using [`contexts/QUALITY_ISSUE_CONTEXT.md`](../contexts/QUALITY_ISSUE_CONTEXT.md).

---

## Stage 3: Crisis Management & Stakeholder Alignment (Day 22 to 45)

**Goal**: Navigate complex, sensitive project dilemmas with structured decision support.

- [ ] Master the 72-hour emergency triage framework in [`contexts/FIRE_RESPONSE_FIRST_72H.md`](../contexts/FIRE_RESPONSE_FIRST_72H.md).
- [ ] Frame scope change requests and trade-offs using [`contexts/SCOPE_CHANGE_CONTEXT.md`](../contexts/SCOPE_CHANGE_CONTEXT.md).
- [ ] Structure schedule recovery scenarios with [`contexts/DELAY_RECOVERY_CONTEXT.md`](../contexts/DELAY_RECOVERY_CONTEXT.md).
- [ ] Calibrate diplomatic client communications using [`contexts/CLIENT_COMMUNICATION_CONTEXT.md`](../contexts/CLIENT_COMMUNICATION_CONTEXT.md).

---

## Stage 4: Advanced Governance & Portfolio Leadership (Day 46+)

**Goal**: Deploy organizational standards, PMO portfolio governance, and automated skill workflows.

- [ ] Conduct cross-project portfolio audits using [`contexts/PMO_REVIEW_CONTEXT.md`](../contexts/PMO_REVIEW_CONTEXT.md).
- [ ] Structure executive decision memos with `.claude/skills/pm-decision-support/SKILL.md`.
- [ ] Establish automated review safeguards using `.claude/skills/ai-output-governance-review/SKILL.md`.
- [ ] Explore structured masterclasses and certifications on the [TechAide Official Platform](https://techaide.jp/?utm_source=github&utm_medium=repository&utm_campaign=ai_toolkit&utm_content=learning_roadmap_site).
