# PM・AI活用 学習ロードマップ

---

## このページの目的

このページでは、リポジトリ内のAI Contextsを使ったあとに、どのPM実務・AI活用テーマを学ぶとよいかを整理します。

AI Contextsはそれぞれの業務場面で役立ちますが、「なぜその観点で整理するのか」「どの順番で考えるべきか」を体系的に理解することで、より実務に活かしやすくなります。
